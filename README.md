# Deezer SEO & GEO Case Study

### Project Overview
This project analyzes Deezer's **Brazil acquisition performance** and proposes an **SEO/GEO strategy for the French Christmas music launch**.

### Key Analyses
- **Brazil Acquisition:** Compared 10 marketing channels using conversion rates and engagement metrics. Recommended reviewing Display and Affiliation.
- **Subscription Growth:** Proposed paid acquisition optimization and organic conversion improvements.
- **Christmas SEO:** Developed keyword research, SEO audit and a before/during/after Christmas action plan.
- **SEO KPIs:** Created a measurement framework covering visibility, traffic, engagement and subscriptions.
- **Christmas GEO:** Tested four French prompts across ChatGPT, Gemini and Perplexity and proposed strategies to improve Deezer's AI recommendations.

### Tools Used
Microsoft Excel, Semrush, Google Trends, Google Search Console (proposed), ChatGPT, Gemini, Perplexity and Lovable AI.

### Methodology & Limitations
The workbook combines supplied Brazil data, exploratory GEO observations and proposed SEO strategies. Hypothetical scenarios are not actual results; some keyword metrics and dashboard values require verification.

### Project Objective
**Turn organic search and AI visibility into measurable engagement and subscriber growth.**
